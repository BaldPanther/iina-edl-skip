# iina-edl-skip — плагин для IINA, пропускающий заставки по файлам `.edl`

Черновое ТЗ для работы в новой сессии. Собрано из проверок, сделанных в сессии
21.09.2026 по проекту `toolbox/media-toolkit`. Кода пока нет — только эта записка.

---

## 1. Зачем

`toolbox/media-toolkit` размечает сериалы: находит интро, титры и recap и пишет
рядом с каждой серией файл `<имя серии>.edl`. **Kodi такие файлы читает и сам
пропускает размеченные куски. Плееры на mpv — нет.**

Хочется смотреть на маке в IINA с тем же авто-пропуском, не заводя ещё одну базу
таймингов: разметка уже есть, лежит рядом с видео и поддерживается в актуальном
состоянии.

## 2. Что уже точно известно (проверено руками)

Всё ниже измерено в этой сессии на macOS, IINA 1.4.4 (внутри mpv 0.38.0).
Это **не** пересказ документации.

### IINA не читает Kodi-овский `.edl`

Опыт: клип на 60 с, рядом `.edl` со строкой `10.000 30.000 3`. Запуск на 5-й
секунде, через 9 секунд позиция — **13.2 с**. То есть плеер прошёл сквозь
размеченный интервал, не перескочив.

Причина: у mpv есть своё понятие «EDL», но это совсем другой формат — описание
склейки кусков в общий таймлайн (`# mpv EDL v0`), а не список пропусков. Сайдкар
рядом с видео mpv вообще не ищет.

### У IINA нет встроенного пропуска заставок

- В бинарнике `/Applications/IINA.app/Contents/MacOS/IINA` и во всех файлах
  локализации бандла слово `intro` не встречается **ни разу**.
- По вебу: в release notes 1.4.x функции нет, в трекере висят два неисполненных
  запроса, помеченных «решать плагином, не в ядре».

### Lua-скрипты mpv в IINA не работают

Проверено двумя способами, оба безрезультатны:

1. `iina-cli --mpv-script=/путь/probe.lua` — скрипт не выполнился;
2. `~/Library/Application Support/com.colliderli.iina/scripts/probe.lua` — тоже.

Песочница исключена: скрипт не смог записать файл даже в собственный каталог
IINA. Вывод: **путь только через JS-плагины IINA**, Lua отпадает.

### Система плагинов

- Установленные плагины лежат в
  `~/Library/Application Support/com.colliderli.iina/plugins/`.
- Сейчас там стоят три: `io.iina.opensub`, `io.iina.user-script`, `io.iina.ytdl`.
- Реальный `Info.json` (взят из плагина User Scripts) выглядит так:

```json
{
  "name": "User Scripts",
  "identifier": "io.iina.user-script",
  "version": "0.9.1",
  "ghVersion": 5,
  "ghRepo": "iina/plugin-userscript",
  "description": "User Scripts for IINA",
  "author": { "name": "IINA Developers", "url": "https://github.com/iina/plugin-userscript" },
  "entry": "dist/index.js",
  "globalEntry": "dist/global.js",
  "permissions": ["show-osd", "network-request", "video-overlay", "file-system"],
  "allowedDomains": ["iina.io", "*.iina.io"],
  "helpPage": "help.html"
}
```

Важное отсюда: разрешение **`file-system`** существует и выдаётся плагинам —
значит, прочитать `.edl` рядом с видео принципиально можно. `ghRepo` + `ghVersion`
нужны для установки и автообновления из GitHub.

### Способ отладки (пригодится, экономит часы)

IINA можно запустить с IPC-сокетом mpv и опрашивать её состояние из Python.
Именно так проверялось, пропустил плеер кусок или нет:

```bash
/Applications/IINA.app/Contents/MacOS/iina-cli \
  --no-stdin --mpv-resume-playback=no \
  --mpv-start=5.000 --mpv-input-ipc-server=/tmp/iina.sock -w "файл.mkv"
```

```python
import socket, json, time
s = socket.socket(socket.AF_UNIX); s.connect("/tmp/iina.sock")
s.send(b'{"command":["get_property","time-pos"]}\n')
time.sleep(0.4)
print(s.recv(4096).decode())     # позиция воспроизведения
```

Работают также `path`, `chapters`, `mpv-version`.

Два флага обязательны, оба выяснены опытом:

- `--no-stdin` — иначе IINA принимает нетерминальный stdin за поданный поток и
  отвечает «не удаётся открыть файл или поток»;
- `--mpv-resume-playback=no` — иначе сохранённая позиция из
  `~/Library/Application Support/com.colliderli.iina/watch_later/`
  (там лежит строка `start=<секунды>`) перебивает `--mpv-start`.

## 3. Формат `.edl`, который надо читать

Пишется модулем `toolbox/media-toolkit/edl.py`, функция `format_edl`.
Пример полного файла:

```
## Recap (в предыдущих сериях)
0.000	42.000	3
## Intro
42.000	102.000	3
## Outro / Credits
3300.000	3533.000	3
```

- Три поля через **табуляцию**: начало, конец, действие. Время — секунды с
  тремя знаками.
- Действие `3` — commercial break. В Kodi это значит «промотать один раз за
  сеанс, но дать отмотать назад». Остальные действия Kodi: `0` — вырезать,
  `1` — заглушить, `2` — метка сцены. Наш инструмент пишет только `3`.
- Строки, начинающиеся с `##`, — комментарии-маркеры. По ним мы отличаем свои
  сегменты; у чужих `.edl` маркеров может не быть.
- Имя файла: то же, что у видео, расширение заменено на `.edl`
  (`Show - S01E02 - Name.mkv` → `Show - S01E02 - Name.edl`).
- Файл может содержать только часть секций — любая из трёх необязательна.

## 4. Как плагин должен себя вести

Решено в обсуждении:

1. **По умолчанию пропускает молча**, как Kodi. Никаких кнопок «Пропустить»,
   которые надо жать.
2. **Каждый сегмент пропускается не более одного раза за просмотр.** Если зритель
   отмотал назад в уже пропущенный кусок — второй раз плеер его не перескакивает.
   Это поведение Kodi для действия `3`, и оно же спасает от «залипания», когда
   перемотка назад сразу отбрасывает вперёд.
3. **Настройки у плагина есть.** Минимум — общий выключатель авто-пропуска.
   Желательно (обсудим позже, не блокирует первую версию):
   - отдельные галки на `Recap` / `Intro` / `Credits`;
   - режим «показывать кнопку вместо авто-пропуска»;
   - короткое уведомление на OSD «заставка пропущена».

Состояние «что уже пропущено» — на время воспроизведения одного файла; при смене
файла сбрасывается.

## 5. Что предстоит выяснить в следующей сессии

Ответов пока нет, гадать не стоит — всё проверяемо:

1. **Как в JS-API IINA следить за позицией.** Есть ли событие/подписка на
   `time-pos`, или нужен опрос по таймеру. Смотреть `docs.iina.io`, раздел
   создания плагинов, и модуль `Core`.
2. **Как перематывать.** Нужен абсолютный seek к концу сегмента. Уточнить
   сигнатуру (`core.seek`), точный это seek или по опорным кадрам — для пропуска
   заставки лучше точный, иначе съедет на секунду-две.
3. **Как у плагина делаются настройки.** В каталоге установленных плагинов есть
   папка `.preferences` — посмотреть, как она устроена у существующих.
4. **Пределы разрешения `file-system`.** Можно ли читать произвольный файл рядом
   с видео или доступ ограничен папкой плагина.
5. **Как отлаживать неупакованный плагин.** У IINA должен быть режим разработчика
   для подгрузки папки, а не архива.
6. **Упаковка и публикация.** По результатам веб-поиска (перепроверить!):
   пакет `.iinaplgz` собирается командой `iina-plugin pack`, установка — через
   Preferences → Plugins → Install from GitHub с указанием `owner/repo`.
   **Значит, нужен публичный репозиторий на GitHub** — иначе этот способ
   установки не работает.

## 6. Что уже есть готового у других (для ориентира, не для копирования)

Найдено веб-поиском, **самостоятельно не проверялось**:

- `pparanoiidd/iina-skip-intro` — есть в официальном каталоге плагинов IINA.
  Определяет заставку по **названиям глав** MKV, опционально по аудиоотпечаткам.
  Kodi-овские `.edl` не читает. Полезен как образец структуры плагина.
- `D0CA/iina-cinemode`, `Zain-Imam/iina-episode-info` — тоже в каталоге,
  темы смежные.
- Официальный список: `github.com/iina/iina/blob/develop/plugins.json`.

Почему не берём готовый: он пляшет от глав, а у нас есть точные границы в `.edl`.
Свой плагин ни от чего не зависит и настраивается как нам нужно.

## 7. Смежное: главы Matroska

В `media-toolkit` уже сделана запись **глав** в сам MKV из той же разметки
(`Cold Open` / `Recap` / `Intro` / `Episode` / `Credits`), через `mkvpropedit`,
без перекодирования. Это отдельный механизм, он уже работает и чужие главы не
трогает.

Для плагина отсюда два следствия:

- Главы — **запасной источник**, если `.edl` рядом нет. Можно предусмотреть, но в
  первой версии не обязательно.
- Проверять плагин удобно на файлах, где главы уже проставлены: видно, совпадают
  ли границы.

## 8. Организационное

- Папка заведена как **соседняя с `toolbox`**, а не внутри него: по правилу из
  `toolbox/CLAUDE.md` утилита, идущая на публикацию, живёт своим репозиторием.
- Репозиторий должен быть **публичным** — установка из GitHub иначе не работает.
- Имя папки (и, вероятно, репозитория): `iina-edl-skip`.
- Стек навязан платформой: JavaScript, система плагинов IINA. Обычное для
  `toolbox` правило «Python + Tkinter» здесь неприменимо.
