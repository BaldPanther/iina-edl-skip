Reads <video>.edl next to the file, the same sidecar Kodi uses. Each segment is skipped at most once per playback, so rewinding back into one plays it normally.
Segments to skip
Sidecars written by media-toolkit label every segment. In files from elsewhere the labels are usually missing, and segments are sorted by position instead: one starting at zero counts as a recap, the last one as credits.
Matroska chapters named Recap, Intro or Credits are used instead. They travel inside the file, so they survive a move that leaves the sidecar behind. A sidecar, when present, always wins.
When a segment runs to the end of the file
Closing credits normally run to the very end, so skipping them ends playback — which is what Kodi does and the default here.
Shortcuts
⌥⌘Z Undo the last skip — go back to where it jumped from, without skipping it again
⌥⌘E Turn auto-skip on or off
Both are also in IINA’s Plugins menu, under EDL Skip, where you can see them without coming back here.
The sidebar has an EDL tab listing the segments of the file being played. Clicking one jumps to its start.
